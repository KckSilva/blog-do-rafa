🗂️ Mapeamento de Unidade de Rede - Windows, Linux e macOS

📋 Introdução ao Mapeamento de Unidades de Rede

O mapeamento de unidades de rede permite acessar pastas compartilhadas em outros computadores ou servidores como se fossem drives locais do seu sistema.

🎯 Para que serve?

  • Acesso facilitado - Pastas de rede aparecem como drives locais
  • Produtividade - Acesso rápido a arquivos compartilhados
  • Colaboração - Compartilhamento de arquivos em equipe
  • Backup - Armazenamento centralizado de dados

🔧 Protocolos Comuns:

  • SMB/CIFS - Windows e compatibilidade com outros sistemas
  • NFS - Common em sistemas Unix/Linux
  • AFP - Apple Filing Protocol (macOS)

🪟 Windows

1 Método Gráfico - Explorer

Passo a passo:

1. Abra o Explorador de Arquivos

2. Clique com botão direito em "Este Computador"

3. Selecione "Mapear unidade de rede..."

4. Preencha:

  • Unidade: Letra desejada (ex: Z:)
  • Pasta: \\servidor\pasta ou \\IP\pasta
  • Conectar usando credenciais diferentes: Marque se necessário

2 Método Linha de Comando - net use

Finalidade: Mapear unidade via Prompt de Comando ou PowerShell.

net use Z: \\servidor\pasta /user:usuario senha /persistent:yes

Explicação:

  • Z: - Letra da unidade
  • \\servidor\pasta - Caminho do compartilhamento
  • /user:usuario senha - Credenciais de acesso
  • /persistent:yes - Manter após reiniciar
net use Z: \\192.168.1.100\shared /persistent:yes

Uso com IP: Mapeamento usando endereço IP diretamente

3 Verificar Unidades Mapeadas

Finalidade: Listar todas as unidades de rede mapeadas.

net use

4 Desmapear Unidade

Finalidade: Remover unidade de rede mapeada.

net use Z: /delete

🐧 Linux

1 Instalar Pacotes Necessários

Finalidade: Instalar cliente SMB para compartilhamentos Windows.

# Ubuntu/Debian sudo apt update && sudo apt install cifs-utils smbclient
# CentOS/RHEL/Fedora sudo yum install cifs-utils samba-client

2 Montagem Manual com mount

Finalidade: Montar compartilhamento SMB temporariamente.

sudo mkdir /mnt/compartilhamento
sudo mount -t cifs //servidor/pasta /mnt/compartilhamento -o username=usuario,password=senha

Mais seguro (sem senha no comando):

sudo mount -t cifs //servidor/pasta /mnt/compartilhamento -o username=usuario

3 Montagem Automática via fstab

Finalidade: Montar automaticamente na inicialização.

sudo nano /etc/fstab

Adicione esta linha ao arquivo fstab:

//servidor/pasta /mnt/compartilhamento cifs username=usuario,password=senha 0 0

4 Desmontar Compartilhamento

Finalidade: Remover compartilhamento montado.

sudo umount /mnt/compartilhamento

🍎 macOS

1 Método Gráfico - Finder

Passo a passo:

1. Abra o Finder

2. No menu superior, clique em "Ir" → "Conectar ao Servidor" (⌘K)

3. Digite o endereço do servidor:

smb://servidor/pasta

4. Clique em "Conectar" e informe as credenciais

2 Método Linha de Comando - mount_smbfs

Finalidade: Montar via Terminal.

mkdir ~/Desktop/Compartilhamento
mount_smbfs //usuario:senha@servidor/pasta ~/Desktop/Compartilhamento

3 Montagem com IP

Finalidade: Usar endereço IP diretamente.

mount_smbfs //usuario@192.168.1.100/pasta ~/Desktop/Compartilhamento

O sistema pedirá a senha ao executar

4 Desmontar no macOS

Finalidade: Remover compartilhamento.

umount ~/Desktop/Compartilhamento

🎯 Dicas e Solução de Problemas:

Problemas Comuns no Windows:

# Verificar se o serviço está executando sc query lanmanserver

Testar Conectividade no Linux:

# Listar compartilhamentos disponíveis smbclient -L servidor -U usuario

Verificar Montagens:

# Linux/macOS - ver montagens ativas mount | grep cifs
🔒 Segurança: Evite deixar senhas em arquivos de configuração. Use arquivos de credenciais com permissões restritas quando possível.
